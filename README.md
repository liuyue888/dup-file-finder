# 重复文件查找器（DupFinder）

一个纯 Python 标准库实现的本地工具：全盘扫描出**不同路径下的重复/雷同文件**，按"能不能删"给出判定，一键移入回收站清理。带网页界面，无需安装任何第三方依赖。

- 纯标准库（`http.server` + `ctypes`），**零第三方依赖**，Python 3.8+ 即可运行
- 网页界面：搜索 / 排序 / 分页 / 打开所在位置 / 勾选删除
- 智能分组：自动剥离文件名里的日期前缀、`@` 标记、`(1)`/`副本`/`copy` 后缀后再判重
- 文件性质判定：程序必要文件 / 缓存临时 / 安装包备份 / 你的文件，附删除建议
- 删除走**回收站**（可还原），删除后该组立即从列表消失
- 内置性能优化：低进程优先级、空闲零轮询、明细懒渲染，扫描不拖慢电脑

## 快速开始

### 方式一：免安装版（推荐给不懂 Python 的同事）

从本仓库右侧 **Releases** 下载 `重复文件查找器_免安装版.zip`（约 10MB，内置 Python 运行库），
**完整解压**后双击 `启动重复文件查找器.bat` 即可，无需安装任何软件。

### 方式二：源码运行（需要 Python 3.8+）

```bash
python finder_app.py
# 然后浏览器打开 http://127.0.0.1:8777
```

Windows 用户也可直接双击 `启动重复文件查找器.bat`（脚本会自动寻找本机 Python）。

> ⚠️ 不要直接双击 `app.html`：那是前端页面，必须连上后台服务才有数据。

## 主要功能

| 功能 | 说明 |
|---|---|
| 全盘扫描 | 默认 C:\ + D:\，自动跳过 Windows / Program Files / AppData 等系统目录 |
| 大小过滤 | 默认只统计 ≥5MB 的文件，可切 1/10/50/100MB（即时生效，无需重扫） |
| 重复分组 | 剥离日期前缀、`(1)`、`副本`、`copy`、`@标记` 后核心名相同即成组 |
| 性质备注 | 🔴 程序必要文件 / 🟢 缓存临时 / 🟠 安装包备份 / 🔵 你的文件 / 🟡 同一份（目录联接） |
| 批量操作 | 单删、Shift 范围勾选批量删、组内"保留建议保留的，其余删除" |
| 忽略本条 | 不想动的组点"忽略"，只隐藏不删除，可随时找回 |
| 打开位置 | 点击路径列，资源管理器直接定位并选中该文件 |

## 安全设计

- **删除一律移入回收站**，可还原；要真正腾空间需最后清空回收站。
- 对程序目录、`.dll/.exe/.pak/.asar` 等程序组件标注"不建议删"。
- 自动识别 **目录联接（Junction）**：同一份文件的两个入口会标记"同一份"，提示删一处两处都会消失。
- 删除成败以**文件是否真的消失**判定，不使用接口返回码，避免误报。

## 环境要求与限制

- Windows 10 / 11（依赖 `ctypes` 调用 `SHFileOperationW` 实现回收站；其他系统需改用 `send2trash`）
- Python 3.8+，仅用标准库
- 单盘扫描约 1～3 分钟（20 万文件量级），期间可正常使用页面
